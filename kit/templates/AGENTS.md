# 작업 지침

- `.context/index.md`에서 현재 요청에 필요한 원본만 찾아 읽는다.
- 요구사항은 index에 등록된 PRD/GDD, 구현 동작은 관련 코드·구성과 실제 검증 결과로 확인한다.
- 상세 컨텍스트 관리 정책은 `.mycodex/context-policy.md`를 참고한다.
- 짧은 작업 규칙만 이 파일에 둔다. 긴 설명은 기존 원본 또는 필요한 주제별 문서에 둔다.
- 설계·계획·진행 원장은 사용 가능한 Superpowers 절차와 기존 문서를 따른다.
- 문서를 만들거나 이동하고 현재 작업을 바꾸면 index의 해당 경로를 갱신한다.
- 실행하지 않은 명령·검증은 미실행으로 기록한다. 기술 스택과 명령을 추정하지 않는다.
- 사용자가 명시적으로 요청할 때 `$project-init` 또는 `$session-handoff`를 호출한다.
- 새 세션에서 이어갈 때 관련 Handoff와 현재 파일·원장·Git 근거를 대조한다.
