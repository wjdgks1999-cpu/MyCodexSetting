# 개발용 AGENTS와 배포용 템플릿 분리

## 승인과 목적

2026-11-16 사용자는 루트 `AGENTS.md`를 MyCodexSetting 개발용으로 만들고, 새 Codex 프로젝트에 설치하는 배포용 지침은 별도로 유지하는 구성을 승인했다.

## 방식

- 루트 `AGENTS.md`: 이 저장소의 목적, 수정 원본, 자체 설치 사본, 검증과 배포 관리 지침.
- `kit/templates/AGENTS.md`: 기존 배포용 원본. 이번 작업에서 내용과 경로를 유지한다.
- `.mycodex/templates/AGENTS.md`: 자체 설치된 배포 템플릿 사본. 개발용 지침을 복사하지 않는다.

## 검토한 대안

기존 `kit/templates/AGENTS.md`가 설치와 배포의 원본이므로 이 경로를 유지하는 안을 채택했다. 배포용 파일을 새 경로에 하나 더 두면 같은 원본을 중복 관리하게 된다. `AGENTS.override.md`에 개발 지침을 두는 안은 루트 `AGENTS.md` 자체를 개발용으로 만들려는 요청과 맞지 않는다.

## 개발용 지침의 내용

기존 원본 탐색·Superpowers·인덱스 갱신·인계 재확인·미실행 구분·사람용 HTML 제외 규칙을 유지한다. `kit/`의 수정 원본, 자체 설치 사본과 manifest의 일관성, 배포 설정과 활성 설정의 구분, 실제 검증 명령, 기존 `dist/` 보존 규칙을 추가한다.

## 범위와 완료 조건

문서만 변경한다. 설치·검증 코드, 배포 템플릿, manifest, 활성 설정, 기존 배포본은 변경하지 않는다. 새 배포 버전이나 ZIP은 만들지 않는다. 변경 전후 배포 파일 목록·내용과 보호 파일 해시가 같고, 구조 검증과 문서 링크 검사가 통과해야 한다.

현재 작업으로 전환하면서 인덱스를 갱신한다. 이전 CLI 확장은 완료 체크된 계획과 검증 기록을 보존하고 추가 문서에서 계속 찾을 수 있게 한다. 작업 완료 후 활성 항목은 `none`으로 정리하고 이번 설계·계획은 완료 기록으로 연결한다.
