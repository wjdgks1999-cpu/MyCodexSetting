# 프로젝트 컨텍스트 관리 정책

## 문서의 역할과 원본

| 정보 | 원본 | 읽는 시점 | 갱신 조건 |
|---|---|---|---|
| 요구사항 | 사용자가 지정한 PRD/GDD | 범위·동작 판단 | 사용자가 요구사항을 변경할 때 |
| 작업 지침 | 적용되는 AGENTS.md/override | 작업 시작 | 실제 명령·작업 제약 변경 |
| 탐색·설정 상태 | .context/index.md | 현재 작업의 원본을 찾을 때 | 초기화, 문서 이동, 승인된 작업 전환 |
| 설계·계획 | 기존 문서 및 Superpowers 문서 | 관련 작업 수행 | 해당 설계·계획의 승인된 변경 |
| 진행 상태 | 현재 계획의 Superpowers 원장과 실제 코드·Git 증거 | 진행 작업 재개 | Superpowers 작업 수행 |
| 장기 결정 | 기존 설계·ADR 우선, 없으면 .context/decisions.md | 관련 결정 판단 | 확인된 결정 추가·대체 |
| 상세 지식 | 기존 원본 우선, 필요시 주제별 문서 | 관련 구조·운영 작업 | 해당 사실 변경 확인 |
| 세션 인계 | .context/handoffs의 시점 스냅샷 | 이어서 하는 작업 | 명시적 $session-handoff 호출 |

짧은 작업 규칙은 AGENTS에, 긴 설명은 해당 주제의 원본에 둔다. project.md와 빈 지식 문서를 기본 생성하지 않는다. 원본이 있는 사실은 반복 요약하지 않고 위치와 용도를 연결한다. Handoff 요약은 작성 시점의 파생 정보로 허용하고 근거를 연결한다.

## 읽기와 갱신

AGENTS → index → 현재 요청에 필요한 원본 순서로 탐색한다. 모든 코드·설계·Handoff 이력을 한꺼번에 읽지 않는다. index 고정 표의 경로는 프로젝트 루트 기준이고 일반 Markdown 링크는 문서 파일 기준이다. 선택하지 않은 항목은 `none`으로 표시한다.

문서 생성·이동·현재 작업 전환 시 해당 작업의 일부로 index의 경로만 갱신한다. 세션 종료 인사나 상태 질문만으로 Handoff를 실행하지 않는다. 전역 기억·설정, 기존 PRD/GDD, 승인된 설계 원문은 Handoff의 요약 작업으로 수정하지 않는다.

## 설정 상태

index의 `needs-review`는 설정 조사가 필요하다는 뜻이고 `ready`는 조사가 끝났다는 뜻이다. PRD만 있고 코드·스택·명령이 미정이어도 정상이다. 초기화 스킬은 실제 사용 가능한 Superpowers를 확인하고 근거를 남긴다. 폴더 하나만으로 사용 가능 여부를 단정하지 않는다. ready는 제품 완료·테스트 통과를 뜻하지 않는다.

## 근거와 재개

확인한 사실, 사용자 결정, 제안, 미확인 사항을 구분한다. 명령을 실행하지 않았다면 미실행으로 기록한다. 실패를 완료로 표시하지 않는다. 비밀 값·사용자 원문 전문을 로그나 Handoff로 복사하지 않는다.

새 세션은 Handoff의 근거와 현재 파일·Git·원장 상태를 대조한다. 과거 테스트 통과를 새 변경 이후의 통과로 재사용하지 않는다. 임시 Superpowers 원장이 정리되면 해당 계획과 Git/검증 근거로 확인하고, 부재만으로 완료를 추정하지 않는다. 다른 계획의 원장을 읽거나 변경하지 않는다.

## 도구

`python .mycodex/mycodex.py validate --target . --json`은 구조·경로·설치 자산 검증이다. 의미적 정확성이나 애플리케이션 동작을 증명하지 않는다. 종료 코드는 정상 0, 검증/충돌 1, 인자/I/O 실행 불가 2이다. `--strict`는 경고도 실패로 처리한다.

설치 자산은 버전별 사본이다. 자동 업데이트·강제 덮어쓰기·전역 설정 변경은 제공하지 않는다. MyCodexSetting 설명서는 삭제해도 이 정책과 스킬·도구가 동작해야 한다.

새 파일은 기존 파일을 교체하지 않는 방식으로 게시한다. Handoff 도구끼리의 index 갱신은 `.context/.index.lock`으로 직렬화하고 임시 파일 작성 직후에도 변경을 확인한다. 잠금에 협력하지 않는 외부 편집기와의 모든 파일 경쟁까지 보장하지는 않는다. 남은 잠금은 다른 작업이 끝났는지 확인한 후 처리한다. 과거 Handoff의 없어진 파일 링크는 재확인 경고이고, 현재 필수 원본 누락은 오류이다.
